# Power BI Healthcare Management Analysis
The project focuses on analyzing healthcare data and developing an interactive Power BI dashboard to provide insights into hospital operations, patient and doctor activity, appointments, revenue, expenses, and other key healthcare performance indicators.

🎯 Project Objective

The objective of this project is to transform healthcare data into meaningful and interactive visual insights that can help understand:

Hospital operational performance | Patient and doctor activity | Appointment patterns | Department performance | Revenue and expense trends | Patient demographics | Financial performance

👩‍💻 Skills Demonstrated

SQL | SSIS | Excel | Power BI | Data Analysis | Data Visualization | ETL | Dashboard Development
