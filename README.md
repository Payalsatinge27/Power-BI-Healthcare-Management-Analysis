# Power BI Healthcare Management Analysis
## 🎯 Project Objective

The objective of this project is to transform healthcare data into meaningful and interactive visual insights that can help understand:

- Hospital operational performance
- Patient and doctor activity
- Appointment patterns
- Department performance
- Revenue and expense trends
- Patient demographics
- Financial performance

- SQL Server
- SSIS
- Excel
- Power BI
- Data Analysis
- Data Visualization
- ETL
- Dashboard Development
